# NEO generated application icon

Created with the built-in image generation tool. The application consumes PNG/ICO raster assets, not SVG.

- Full-resolution generated source: `../src/App/Resources/NEO-generated.png`.
- UI PNG: `../src/App/Resources/NEO.png`.
- Windows ICO: `../src/App/Resources/NEO.ico`.
- Packaging: `../scripts/create-icon.ps1` resizes the generated raster and packages 16–256 px ICO entries. It does not draw or regenerate the logo.

## Generation prompt

Create one production-ready raster application icon for NEO, a native Windows AI assistant. A clean elegant interlocking monogram combining uppercase N and lowercase e into ONE cohesive white mark. Minimal geometric rounded strokes, excellent legibility at 24px, balanced optical spacing. Center the mark on a single light royal blue rounded-square app tile with a very subtle blue gradient (#6292FF to #315DDF). Straight-on flat icon, no perspective, no 3D extrusion, no surrounding frame, no mockup, no other text or letters, no decorations, no drop shadow. Transparent pixels outside the rounded-square tile, tile fills almost the whole square canvas with only 4 percent outer padding. Polished simple modern Windows / Apple app-icon clarity. High resolution square PNG with real alpha transparency. This is the final icon asset, not a presentation sheet.
